Raku 是一个**沉浸式日语阅读学习平台**。你上传一篇文章或一段视频，应用会自动断句、翻译、生成语法讲解和朗读音频；你在阅读器里逐句精读，把句子和生词收藏成可复习的卡片。

本指南只讲**如何使用 App 的界面**，不涉及安装或部署。

## 第一次打开

打开 App 会看到欢迎界面，中间是应用名称 **Raku Learning Language**，下方有两个按钮：

- **登录**：已有账号，从这里进入。
- **注册**：第一次使用、需要用邀请码创建账号。

<Frame caption="欢迎界面：点击“登录”或“注册”继续">
  <img src="/images/user-guide/01-welcome.png" alt="Raku 欢迎界面" />
</Frame>

Raku **没有用户名和密码**，一律使用第三方账号或通行密钥登录，因此无需记住额外密码。

## 登录

在欢迎界面点击 **登录**，勾选“**我已阅读并同意隐私政策**”后，选择一种登录方式：

- **使用 Google 登录**
- **使用 GitHub 登录**
- **使用微信登录**（仅在服务端启用了微信的环境显示）
- **使用通行密钥登录**（仅网页版，见下文“通行密钥”一节）
- 不想登录可点 **不登录，先逛逛**（见下文“访客模式”说明）

登录页**不需要邀请码**，也没有邀请码输入框。在授权页选择你的账号后即可进入主界面。App 会**记住登录状态**，下次打开自动进入；右上角账号菜单里可以 **退出登录**。

<Note>
  如果你选的第三方账号**尚未注册**，会先看到“**该账号尚未注册**”。此时点击“**还没有账号？立即注册**”，输入有效邀请码即可完成注册，**无需再次跳转授权**。注意不要用一个已经绑定到其他账号的登录方式去注册新账号，规则见下文。
</Note>

## 注册新账号

新用户采用**邀请制**，需要一枚有效的**邀请码**（向管理员或拥有个人邀请码的用户索取）。在欢迎界面点击 **注册**：

<Steps>
  <Step title="填写邀请码">
    在“邀请码”输入框填入有效邀请码。邀请码只在注册时填写。
  </Step>
  <Step title="同意隐私政策">
    勾选“**我已阅读并同意隐私政策**”，可点击“隐私政策”查看全文。
  </Step>
  <Step title="选择注册方式并授权">
    点击“**使用 Google 注册**”或“**使用 GitHub 注册**”（启用微信的环境还会显示“**使用微信注册**”），在授权页完成授权。
  </Step>
</Steps>

邀请码有效时，账号会**立即创建并激活**，直接进入主界面，没有人工审核等待；邀请码无效或已停用则会在页面上提示错误，修改后重试即可。注册页底部可点“**已有账号？立即登录**”返回登录。

## 登录方式与账号的绑定规则

一个 Raku 账号可以同时绑定**多个**登录方式（Google、GitHub、微信各一个），但要注意：

<Note>
  **一个第三方账号只能属于一个 Raku 账号。** 已经绑定到某个账号的微信 / Google / GitHub，无法再拿去注册或绑定另一个账号。注册页上也有这条提醒：**已有账号请直接登录**，不要误用老的登录方式去注册新号，否则会得到“该登录方式已被其他账号使用”一类的错误。
</Note>

- 每种登录方式在一个账号下**最多绑定一个**（例如不能同时绑两个 Google）。
- 想把更多登录方式加到当前账号，登录后到 **账号设置** 里操作，见下一节。
- 登录方式的归属以授权身份为准，切换绑定前请确认用的是自己的第三方账号。

## 在账号设置里管理登录方式

登录后，打开右上角账号菜单进入 **账号设置**，可以：

- **绑定**：把未被其他账号使用的 Google / GitHub / 微信关联到当前账号（绑定会跳转一次第三方授权）。
- **解绑**：移除已绑定的登录方式。

为防止把自己锁在门外，系统**不允许解绑最后一种登录方式**——账号下必须至少保留一种可登录的方法（至少保留一个第三方登录；通行密钥不能作为唯一登录方式）。

## 通行密钥（Passkey）

通行密钥是一种**免密码**登录方式：在网页版用设备的**指纹、面容或安全密钥**即可登录，无需再走第三方授权。

规则如下：

- **仅用于登录，不能用来注册新账号**。通行密钥只会匹配到一个**已经存在**的账号。
- **仅网页版提供**（手机 / 桌面 App 不显示该入口）。
- 第一次使用前，需要先**用 Google 或 GitHub 登录一次**，然后在 **账号设置 → 通行密钥** 中注册一枚通行密钥。
- 在账号设置里可以为通行密钥**命名 / 重命名**、注册多枚、以及**删除**不再使用的密钥。
- 若一枚通行密钥匹配不到任何已知账号，会提示你先用 Google 或 GitHub 登录。

## 不登录，先逛逛

欢迎界面选择登录后，登录页底部有“**不登录，先逛逛**”按钮。点击后以**访客身份**直接进入主界面，可以浏览公开语料、查看已有翻译、讲解和语法卡片，也能播放已生成的音频。

访客**不能**上传内容、收藏文章或句子、加入生词本；点击这些操作时会引导你登录。

## 切换界面语言

在任意页面**右上角**点击语言按钮（显示当前语言、带翻译图标），即可在 **English / 简体中文 / 繁體中文 / 日本語** 之间切换。你的选择会被记住，下次打开自动沿用。

<Note>
  切换的是**界面语言**；文章的翻译与语法讲解内容由后端生成，不随界面语言改变。
</Note>
