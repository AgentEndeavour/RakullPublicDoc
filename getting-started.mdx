Raku 是一个**沉浸式日语阅读学习平台**。你上传一篇文章或一段视频，应用会自动断句、翻译、生成语法讲解和朗读音频；你在阅读器里逐句精读，把句子和生词收藏成可复习的卡片。

本指南只讲**如何使用 App 的界面**，不涉及安装或部署。

## 第一次打开

打开 App 会看到欢迎界面，中间是应用名称 **Raku Learning Language**，点击 **登录** 进入登录页。

<Frame caption="欢迎界面：点击“登录”继续">
  <img src="/images/user-guide/01-welcome.png" alt="Raku 欢迎界面" />
</Frame>

## 登录

已有账号时，在登录页勾选“**我已阅读并同意隐私政策**”，然后选择“**使用 Google 登录**”或“**使用 GitHub 登录**”，在授权页面选择你的账号。可点击“隐私政策”查看全文。

登录页不显示邀请码，也无需输入邀请码。登录成功后进入学习主界面。App 会**记住你的登录状态**，下次打开自动进入，无需重复登录。右上角的账号菜单里可以 **退出登录**。

## 注册新账号

还没有账号时，在登录页点击“**还没有账号？立即注册**”，进入注册页：

<Steps>
  <Step title="填写邀请码">
    输入有效的**邀请码（Invite code）**，可向管理员或拥有个人邀请码的用户获取。邀请码仅在注册时填写。
  </Step>
  <Step title="同意隐私政策">
    勾选“**我已阅读并同意隐私政策**”。
  </Step>
  <Step title="选择注册方式">
    点击“**使用 Google 注册**”或“**使用 GitHub 注册**”，完成第三方账号授权。
  </Step>
</Steps>

有效邀请码会直接完成注册并进入学习主界面。邀请码无效时，注册页会显示错误；修改后点击“**注册**”即可复用刚才的授权重试。

<Note>
  如果尚未注册的账号从“登录”入口完成了授权，会先看到“**该账号尚未注册**”提示。点击“**立即注册**”后，再填写邀请码并同意隐私政策，点击“**注册**”完成注册，无需再次跳转授权。
</Note>

在注册页点击“**已有账号？立即登录**”可返回登录页。

## 不登录，先逛逛

登录页底部有“**不登录，先逛逛**”按钮。点击后以**访客身份**直接进入主界面，可以浏览公开语料、查看已有翻译、讲解和语法卡片，也能播放已生成的音频。

访客**不能**上传内容、收藏文章或句子、加入生词本；点击这些操作时会引导你登录。

## 切换界面语言

在任意页面**右上角**点击语言按钮（显示当前语言、带翻译图标），即可在 **English / 简体中文 / 繁體中文 / 日本語** 之间切换。你的选择会被记住，下次打开自动沿用。

<Note>
  切换的是**界面语言**；文章的翻译与语法讲解内容由后端生成，不随界面语言改变。
</Note>
